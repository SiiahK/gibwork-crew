# gibwork-crew — Gibwork Developer Hackathon (non-web-app track)

Repository: https://github.com/SiiahK/gibwork-crew (MIT)
Gibwork toolset used: the official Gibwork SDK (@gibwork/sdk) for discovery and submission, plus our own MCP server.

gibwork-crew lets an agent take a Gibwork bounty, split it into subtasks and pay sub-agents on verified delivery
(USDC escrow on Solana, released on a matching SHA-256 or on the payer's approval), then submit the assembled work.
CLI + MCP server, no web app, dry-run unless --yes. Setup, environment, commands with real output and the
mainnet run are in the README.
